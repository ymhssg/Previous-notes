用户命令
-------------------------------------------
	yarn的主要构成
	---资源管理器rm  :  全局的资源管理器,负责资源的管理和分配
	---节点管理器nm :  每个节点的资源和任务管理器,(向rm汇报资源使用情况,容器运行状态
			---负责处理应用程序主控的容器运行,停止请求)
	--应用程序主控am : 与rm通信以获得更多资源 --与nm通信,内部分配任务
	--容器container :  YARN中的基本执行单位

	yarn application [options]  应用程序状态处理
		-----list：返回RUNNING状态的application 任务
		-----kill <ApplicationId>：kill掉指定的应用程序
		-----status <ApplicationId>：打印应用程序的状态。

	yarn applicationattempt [options]  显示应用程序尝试的报告
		-----list <ApplicationId>:获取到应用程序尝试的列表
		-----status <Application Attempt Id>: 打印应用程序尝试的状态

	yarn classpath  显示hadoop的jar和lib包路径
	
	yarn container [options]
		-----list <Application Attempt Id>：打印应用程序尝试的Containers列表
		-----status <ContainerId>：打印Container的状态

	yarn jar 打包和运行jar文件

	yarn logs -applicationId <application ID> [options]    打印container的日志
		-----applicationId <application ID>：指定应用程序ID
		-----appOwner <AppOwner>：应用的所有者
		-----containerId <ContainerId>：Container Id


	yarn node [options] #打印节点报告
		----all  所有节点
		----list 列出所用running状态的节点
		----states <States>  只显示这些状态的节点信息
		-----status <NodeId>  	显示指定节点的状态

	yarn queue [options] #打印队列信息
		-----help     #帮助
		-----status <QueueName>  # 打印队列的状态
